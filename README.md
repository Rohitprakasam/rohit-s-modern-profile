# Rohit Prakasam - System Administrator Portfolio

## Project Info

This is the personal portfolio website for Rohit Prakasam, a System Administrator. It showcases his skills, experience, and projects.

## Tech Stack

-   **Frontend Framework**: React
-   **Build Tool**: Vite
-   **Language**: TypeScript
-   **Styling**: Tailwind CSS
-   **Component Library**: shadcn-ui
-   **3D Graphics**: Spline

## Local Development

To run this project locally:

1.  **Clone the repository**:
    ```sh
    git clone <YOUR_GIT_URL>
    ```

2.  **Install dependencies**:
    ```sh
    npm install
    ```

3.  **Start the development server**:
    ```sh
    npm run dev
    ```

4.  **Open in browser**:
    Navigate to `http://localhost:8080` (or the port shown in your terminal).
